# MENGO Interactive Report & Deck

A web application translating the MENGO strategic AI roadmap into an interactive, presentation-ready dashboard.

## Features
- **Presentation Deck Mode:** Step through slides using `Previous` and `Next` buttons or jump straight to any section.
- **Input Diagnostic Widget:** Test input quality score to demonstrate why generic inputs lead to generic outputs.
- **Dynamic 1-to-100 Multiplier:** Type in a single core strategy and generate a real-time breakdown of social posts, ad angles, and sales touchpoints.
- **Clean Dark Theme:** Custom CSS featuring dark glassmorphism, accent typography, and smooth CSS keyframe transitions.
